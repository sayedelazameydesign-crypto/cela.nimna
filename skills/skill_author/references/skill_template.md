# قالب SKILL.md

```markdown
---
name: skill_name              # مطلوب: حروف صغيرة، أرقام، - أو _
display_name: اسم معروض        # اختياري
description: متى تُستخدم هذه المهارة وماذا تنتج (جملة أو جملتان). # مطلوب
version: 1.0.0
triggers:                      # كلمات/عبارات تساعد المخطط على الاختيار
  - كلمة مفتاحية
  - keyword
allowed_tools:                 # الأدوات التي تُفتح عند تحميل المهارة (من قائمة الأدوات المسجلة فقط)
  - read_file
tags: [category]
---

## متى تُستخدم
...

## التعليمات
1. خطوة واضحة قابلة للتنفيذ.
2. ...

## قائمة التحقق قبل الرد النهائي
- [ ] ...

## حدود المهارة
- لا تفعل ...
```

## بنية المجلد

```
skills/skill_name/
├── SKILL.md          # مطلوب
├── references/       # وثائق يقرأها الوكيل عند الحاجة بـ read_skill_reference
├── scripts/          # سكربتات مساعدة (تُشغَّل عبر run_python)
└── tests/            # أمثلة طلبات ونتائج متوقعة
```

## مبادئ الكتابة الجيدة

- الوصف هو ما يراه المخطط قبل تحميل المهارة؛ اجعله دقيقًا ومحددًا.
- ضع التفاصيل الطويلة في `references/` بدل تضخيم SKILL.md.
- اذكر الأدوات بأسمائها الحرفية.
- عرّف شروط طلب الموافقة (الحذف، الكتابة فوق ملفات، الإرسال).

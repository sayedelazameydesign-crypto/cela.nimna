# دليل التحكم في الكمبيوتر — Nimna Computer Control

## نظرة سريعة
البيئة هي حاوية معزولة لا تلمس جهازك:
- `dorowu/ubuntu-desktop-lxde-vnc:focal` أو `kasmweb/ubuntu-jammy-desktop`
- المنافذ: `5901` (VNC) و `6901` (noVNC — عرض في المتصفح)
- المتغيرات: `VNC_RESOLUTION=1280x800`, `VNC_PW=nimna`

## كيف تبدأ
```bash
# تفعيل سطح المكتب المعزول
docker compose --profile computer up -d desktop
# افتح المعاينة
xdg-open http://localhost:6901  # أو شاهد Mirror View في Nimna
# اختبر
nimna ask "التقط صورة للشاشة وأخبرني ماذا ترى"
```

## إحداثيات الشاشة
- الأصل (0,0) أعلى اليسار، (1280,800) أسفل اليمين.
- استخدم `take_screenshot` أولاً، ثم حدد x,y بناءً على ما تراه.
- لا تخمن — إذا لم ترَ الزر، اطلب لقطة جديدة بعد تمرير أو فتح قائمة.

## الأدوات باختصار
| الأداة | موافقة | وصف |
|---|---|---|
| `take_screenshot` | لا | يلتقط PNG مع شبكة إحداثيات ويعيده base64 + يحفظه في `workspace/.screenshots/` — يكسر حلقة اللقطات إذا تكررت 3 مرات |
| `get_element_coordinates(element)` | لا | **جديد** — يحدد (x,y) بدقة عبر OCR/شبكة لتجنب توهان الإحداثيات |
| `mouse_click(x,y, button, clicks)` | نعم (بصرية) | نقرة مع نقطة حمراء للمراجعة — استخدم الإحداثيات من الأداة السابقة |
| `type_text(text, submit)` | نعم | كتابة مع محاكاة تأخير واقعي |
| `shell_execute(command)` | نعم | تشغيل أمر في `/bin/bash` داخل الحاوية مع حماية موارد صارمة (ulimit + timeout) |

## نمط التفكير
اعرض دائمًا في واجهة البطاقات:
- ما لاحظته في اللقطة
- ما تخطط لفعله مع الإحداثيات
- ما تتوقع حدوثه بعد التنفيذ
ثم نفذ وتأكد بلقطة جديدة.

## الأمان
- الحاوية معزولة بشبكة `nimna-net` ولا تملك وصولاً لملفات مضيفك إلا عبر `workspace` المربوطة قراءة/كتابة.
- لا تستخدم `shell_execute` لحذف `/` أو لتنزيل برمجيات مجهولة.
- كل نقرة/كتابة/أمر يظهر في سجل التدقيق `audit_log` مع `approved=true/false`.

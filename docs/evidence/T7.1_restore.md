# T7.1-A — إغلاق سلامة الاستعادة (أدلة كاملة، مُشغَّلة 2026-09-23)

## 1) تجزئتان كاملتان (64 hex) + الأمر المستخدم

```
$ sha256sum tests/test_binding_migration.py
6c8cb2739e4ad10257b53813ae6dfaebbf8eb2098674f743fd39ec047e43902e  tests/test_binding_migration.py

$ git show 8b12a8e:tests/test_binding_migration.py | sha256sum
6c8cb2739e4ad10257b53813ae6dfaebbf8eb2098674f743fd39ec047e43902e  -
```

**المحتوى المُلتزم == المحتوى المُختبَر، بايتياً.** (العرض السابق `6c8cb2739e4ad102`
كان مقتطعاً — هذا هو الكامل، وهو امتداد نفس البادئة.)

## 2) حدث إعادة البناء وسجل الاستعادة (أدلة)

عاد الـ sandbox بـ HEAD=49d84d0 والملفات كتعديلات. الإجراء:

```
$ sha256sum tests/test_binding_migration.py > /tmp/pre_reset.sha
$ git fetch origin arena/01a0ceff-cela-nimna
$ git rev-parse FETCH_HEAD
8b12a8eb48d8cc5acb4a4cc56d84db9623886373
$ git ls-files -m | while read f; do a=$(sha256sum "$f"|cut -d' ' -f1);
    b=$(git show "FETCH_HEAD:$f" 2>/dev/null | sha256sum | cut -d' ' -f1);
    [ "$a" = "$b" ] && echo "MATCH $f" || echo "DIFF  $f"; done
MATCH CONTRIBUTING.md        MATCH README.md
MATCH docs/CAPABILITY-MATRIX.md   MATCH docs/VERIFICATION-MATRIX.md
MATCH nimna/agents/base.py   MATCH nimna/bootstrap.py
MATCH nimna/config.py        MATCH nimna/core/agent.py
MATCH nimna/core/planner_swarm.py MATCH nimna/tools/builtin/__init__.py
$ git reset --hard FETCH_HEAD
HEAD is now at 8b12a8e T7.1: VNC-path tests pinned + mutation harness moved into the repo
```

**10/10 ملفات متتبَّعة MATCH قبل الـ reset** — لا ضياع، ولا فرق بايتي.

## 3) verify-commit للثلاثة — المخرج الحقيقي

```
$ git verify-commit d50d755 ; git verify-commit 3cc4aa8 ; git verify-commit 8b12a8e
(لا مخرج، لا أخطاء)

$ git log --format="%h %G? %GK" -4
8b12a8e N
3cc4aa8 N
d50d755 N
f13ba6a N
```

**`%G? = N` للاثلاثة: الـ commits غير موقّعة PGP** — بيئة الـ sandbox بلا مفتاح
GPG، لذا `verify-commit` لا يجد توقيعاً يتحقق منه (مخرجه الصامت هو الحال
المتوقعة لـ commit غير موقَّع). **الادعاء المسموح:** لا يوجد تحقق توقيعي؛
الرساة البديلة المثبتة أعلاه: sha256 للمحتوى + rev-parse للهويات + ls-remote
للمطابقة مع الريموت. توقيع الـ commits يتطلب مفتاح GPG يوفَّر خارج هذه البيئة.

## 4) rev-parse كامل + HEAD = origin

```
$ git rev-parse d50d755 3cc4aa8 8b12a8e HEAD
d50d7556f41b40e38e603acf1729c995fdb4d3c5
3cc4aa8c8a4d803bc10485939c811c04fbdbe607
8b12a8eb48d8cc5acb4a4cc56d84db9623886373
8b12a8eb48d8cc5acb4a4cc56d84db9623886373        ← HEAD

$ git ls-remote origin arena/01a0ceff-cela-nimna
8b12a8eb48d8…  refs/heads/arena/01a0ceff-cela-nimna
```

**HEAD == 8b12a8e == origin.** (ملاحظة: مُراجِعك كتب `3cc4aa8e` — الكامل
`3cc4aa8c8a4d803bc10485939c811c04fbdbe607`.)

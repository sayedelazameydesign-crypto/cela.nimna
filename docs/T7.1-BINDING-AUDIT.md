## 3. الأسلاك الإنتاجية (Wiring)

- **`bootstrap.build_agent`** (`bootstrap.py:25`): يبني `Agent` **بلا gateway** —
  لا باراميتر أصلاً في المصنع. أي أن مدخل الإنتاج الفعلي = المسار القديم لكل شيء.
- **`run_arena_suite._build_agent`**: الـ Agent نفسه بلا gateway (الـ Gateway
  مستخدم للـ verifier فقط — وهذا مقصود في T7).
- توقيع `Agent` يقبل `execution_gateway=` منذ T7، لكن لا موقع إنتاجي يمرره.

### عقد التوجيه الآن (مُنفَّذ في `core/agent.py::_run_tool` و`agents/base.py`)

| الشرط | المسار | Audit |
|---|---|---|
| gateway=None | legacy — **توافق مُصرَّح** (غير مصنَّف bypass) | — |
| gateway مقيَّد + الأداة **مسجَّلة** | `gateway.invoke_for_agent` → Fabric كامل | سجل gateway موحّد |
| gateway مقيَّد + في `gateway.compat_tools` (**إعلان صريح**) | legacy | `gateway_compat` |
| gateway مقيَّد + غير ذلك | **REFUSED قبل المعالج** (`NOT_IN_GATEWAY`) | `gateway_refused` |
| فشل الـ Gateway نفسه (استثناء) | **GATEWAY_ERROR** — لا fallback إلى legacy أبداً | `gateway_error` |

- `ExecutionGateway(compat_tools=...)` افتراضي **فارغ** ⇒ الربط صارم إلا بإعلان.
- `invoke_for_agent` مدخل مشترك للوكيل والـ Swarm — الـ grant الافتراضي يتبع
  **طالب التنفيذ** (الربط هو الموافقة) لا actor ثابتاً.
- Swarm: `BaseSwarmAgent(execution_gateway=...)` + التوصيل من `parent_agent`
  في `planner_swarm.py` — نفس التوجيه الثلاثي.
- `bootstrap.build_agent(execution_gateway=...)` — البوابة تصل مدخل الإنتاج.
